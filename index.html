Brahmand Ganga — Space + Health + Earth

By MVA Robotics Innovation Org, Ranchi, Jharkhand • Founder: Ashish Kumar

From Astronaut to Farmer — One Platform for Space and Earth.

Open Brahmand Ganga →← Back to Home

Problem Statement

Problem 1: Astronaut Health Risk in Space

Astronauts on ISS face heart rate changes, low oxygen, bone loss, sleep disorder, stress, radiation exposure. There is no simple, low-cost, real-time system that predicts health risk early using AI. By the time a doctor sees the problem, it is already late.

Problem 2: No Easy Access to ISS and Space Data for Students

NASA has open data, but students in India, especially in rural areas, cannot understand it. It is in complex formats, APIs, and English technical language. A student in Ranchi cannot see where ISS is right now, or what space weather is today.

Problem 3: Space Weather Affects Earth But No One Gets Alert

Solar flare, geomagnetic storm, radiation affect satellites, GPS, mobile network, power grids, and farmers who use GPS for farming. Common people get no alert in simple language.

Problem 4: Ganga Basin — Water, Flood, Crop Problems

Ganga basin is lifeline for 40 crore people. But water quality, flood, crop disease are checked manually, late, and in papers. No real-time Computer Vision system to check Ganga water, flood risk, and crop health from satellite images.

Problem 5: Space and Earth Are Treated Separately

Space projects are only for space. Earth projects are only for Earth. No project connects both. But same technology — ML + Computer Vision — can solve both.

Main Problem Statement in One Line:
How to build one low-cost, AI-powered platform that monitors astronaut health in space, tracks ISS live, gives space weather alerts, and at the same time monitors Ganga water, flood and crops on Earth — for students, doctors, farmers and scientists?

Solution — Brahmand Ganga

Brahmand Ganga is one web platform with 4 main modules:

Module 1: Astronaut Health Monitoring

ML model reads heart rate, SpO2, sleep, temperature, stress. It predicts Health Risk Score — Low / Medium / High. If High, it gives red alert to doctor / mission control.

Module 2: ISS Live Tracking

Live map shows where ISS is right now. Shows speed, altitude, latitude, longitude, orbit path. Students can see ISS passing over India live.

Module 3: Space Weather Dashboard

Shows solar flare, KP index, radiation level, geomagnetic storm. Gives alert in simple language: Safe / Caution / Danger. For satellite operators and common people.

Module 4: Ganga Basin Monitoring

Computer Vision checks satellite images for:

  • Ganga water quality — clean / polluted / algae
  • Flood risk — water level rise
  • Crop health — healthy / disease / dry

One Solution, Two Worlds

Brahmand (Space)

Astronaut + ISS + Space Weather

Ganga (Earth)

Water + Flood + Crop

Technology Used

Frontend

  • HTML, CSS, JavaScript
  • Responsive Design — Works on mobile, laptop, low internet
  • Leaflet Map for ISS tracking

Backend

  • Python + FastAPI
  • REST APIs — Fast, clean, separate
  • JSON data handling

Machine Learning

  • Python, Scikit-Learn, Pandas, NumPy
  • Health Risk Prediction Model — Classification Model
  • Training data: Heart rate, SpO2, sleep, temperature, activity
  • Output: Risk Score 0-100 + Low / Medium / High

Computer Vision

  • OpenCV, Python
  • Image processing for water, crop, flood
  • Water color detection, vegetation index, flood area detection

Data Sources

  • NASA Open Data APIs
  • Open Notify ISS API — ISS live position
  • NASA DONKI / Space Weather API — Solar flare, storm
  • Sentinel / Landsat Satellite Images — Ganga basin (demo images)

Cloud & Deployment

  • Vercel — Frontend hosting
  • GitHub — Code management
  • Firebase — Optional data storage

Why This Stack?

Same stack used by real companies. Frontend separate, Backend separate, ML separate. Easy to scale, easy to maintain.

Architecture — How It Works

Step-by-Step Architecture

User (Student / Doctor / Farmer)
↓
Website (Vercel) — Brahmand Ganga Frontend
↓
Python Backend (FastAPI) — 4 APIs
↓
Health ML ModelISS API (NASA)Space Weather API (NASA)CV Model (OpenCV)
↓
Result Back To User in 1-2 Seconds

Detailed Flow

  1. User Opens Website: Selects module — Health / ISS / Weather / Ganga
  2. Frontend Sends Request: JavaScript calls FastAPI endpoint, e.g., /predict-health, /iss-live, /space-weather, /check-ganga
  3. Backend Processes:
    • Health: ML model takes inputs, returns Risk Score
    • ISS: Calls NASA ISS API, returns lat, lon, speed, altitude
    • Weather: Calls NASA Space Weather API, returns KP index, flare status
    • Ganga: CV model processes satellite image, returns water / crop status
  4. Result Display: Frontend shows card, color, map, chart, alert in simple language
  5. Alert System: If Risk = High or Storm = Danger, card turns Red + Warning message

Database Flow

  • Live data — No heavy database needed, uses NASA APIs live
  • User data — Optional Firebase for saving health history

  • Can see history and take action early

Use Case 2: Student / School

  • Student opens site, sees ISS live over India
  • Learns space science in real time, not from book
  • Teacher uses it in classroom for NASA Space Apps learning

Use Case 3: Farmer in Ganga Basin

  • Farmer checks flood risk before sowing
  • Checks crop health from satellite image
  • Gets space weather alert if GPS will fail

Use Case 4: Scientist / Researcher

  • Researcher uses Ganga water data for pollution study
  • Uses space weather data for satellite safety
  • Can download data for paper

Use Case 5: Common Person

  • Common person checks: Is today safe for satellite TV? Is Ganga water clean near my city?
  • Gets answer in simple Hindi / English, not technical data

Use Case 6: Disaster Management

  • Flood department sees flood risk early in Ganga basin
  • Can send evacuation alert 1-2 days early

Working Functionality — What User Sees and Does

Home Page

  • Shows 4 cards: Astronaut Health, ISS Tracker, Space Weather, Ganga Monitoring
  • User clicks any card

Functionality 1: Astronaut Health Page

  • User enters: Heart Rate, SpO2, Sleep Hours, Temperature, Stress Level
  • Clicks: Check Health Risk
  • Output: Risk Score e.g., 78/100 — High Risk — Red Alert + Suggestion: Take rest, check oxygen, contact doctor
  • Shows chart: Heart rate trend

Functionality 2: ISS Tracker Page

  • Map shows ISS moving live
  • Shows: Latitude, Longitude, Speed — 27,600 km/h, Altitude — 420 km
  • Button: Where is ISS now? — Updates every 5 seconds
  • Shows: Next pass over Ranchi / India

Functionality 3: Space Weather Page

  • Shows: KP Index, Solar Flare Level, Radiation
  • Color: Green = Safe, Yellow = Caution, Red = Danger
  • Alert: “Today geomagnetic storm possible — GPS may be weak”

Functionality 4: Ganga Monitoring Page

  • User selects: Location — Prayagraj / Varanasi / Patna / Haridwar
  • Uploads or selects satellite image
  • Clicks: Check Water / Crop
  • Output: Water — Moderately Polluted, Crop — Healthy, Flood Risk — Low
  • Shows image with marking

Other Functionalities

  • Language: English / Hindi / Hinglish
  • Mobile friendly — Works on low internet
  • No login needed for demo — Easy for students
  • All modules work independently — If one API fails, others still work
