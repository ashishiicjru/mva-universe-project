OPTIONAL: put your own texture files in this folder to make the pages work fully offline.
If a file is missing, the page automatically tries an online copy, and if that also fails it draws
a generated surface, so nothing ever breaks.

Recognised file names (equirectangular 2:1 images, 2048x1024 is a good size):
earth.jpg  earth_normal.jpg  earth_specular.jpg  earth_clouds.png
moon.jpg  sun.jpg  mercury.jpg  venus.jpg  mars.jpg  jupiter.jpg  saturn.jpg  saturn_ring.png
uranus.jpg  neptune.jpg  ceres.jpg  pluto.jpg  eris.jpg  haumea.jpg  makemake.jpg

Free real NASA-based maps: https://www.solarsystemscope.com/textures/  (CC BY 4.0, credit required)
and https://visibleearth.nasa.gov  (public domain).
