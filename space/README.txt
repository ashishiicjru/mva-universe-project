MVA Space - 10 interactive space pages
=======================================
Pages (15): earth, moon, sun, inner-planets, gas-giants, ice-giants, dwarf-planets,
       solar-system, milky-way, universe-black-hole  (all .html)
       plus 5 very large full-screen views: earth-large, sun-large, mars-large,
       saturn-large, jupiter-large
Shared:  css/space.css   js/space-data.js   js/space-common.js
Extra:   js/solar-system.js  js/milky-way.js  js/universe-black-hole.js
Folder:  assets/textures/ (optional local images, see README inside)

To preview: open any page through a local web server (for example "npx serve" or
VS Code Live Server), because browsers block textures loaded from file://.
The pages need internet for three.js (cdnjs/jsdelivr) and Google Fonts.

Connecting to your site comes next: the "MVA Space" brand link goes to ../index.html
(change HOME at the top of js/space-common.js if your layout differs).
